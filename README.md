# Smart Personal Assistant – Task Management Dashboard

## 📌 Overview

The Smart Personal Assistant is a Python-based project designed to help users manage their daily tasks and events efficiently. It allows users to add tasks, assign priorities, track task completion, and organize important activities in one place.

The project uses a **priority queue implemented with a min-heap** to manage tasks according to their priority. It also stores task and event information in CSV files, making it easier to save and retrieve data.

An interactive web-based dashboard provides visual representations of task statistics using charts, helping users understand their completed and pending tasks. The project combines Python programming, file handling, data management, and web-based visualization to create a simple and useful personal productivity tool.

## ✨ Features

- **Task Management:** Add, view, and organize daily tasks.
- **Priority-Based Scheduling:** Manage tasks using a min-heap priority queue.
- **Task Tracking:** Track completed and pending tasks.
- **Event Management:** Store and manage important events.
- **Data Persistence:** Save tasks and events in CSV files.
- **Interactive Dashboard:** Display task statistics through a web interface.
- **Data Visualization:** Present task information using bar charts and pie charts.
- **Python Integration:** Combine task management functionality with web-based visualization.

## ⚙️ How It Works

1. The user interacts with the Python-based application.
2. Tasks can be added with priorities and additional notes.
3. The application organizes tasks using a priority queue.
4. Task and event information is stored in CSV files.
5. The dashboard displays task statistics and visual charts.
6. Users can review their task progress through the visualization page.

## 🎯 Objective

The main objective of this project is to simplify daily task management, improve productivity, and provide a clear visual overview of personal activities. It also demonstrates the practical use of Python data structures, file handling, and web technologies in a real-world application.
